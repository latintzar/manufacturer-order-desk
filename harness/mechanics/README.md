# Shared mechanics

Durable per-company access, files, membership, funding, tools, conversations and workspace services live here. Runtime and SDK modules compose these mechanisms; the selected manufacturer vertical supplies its business rules and native surfaces.

Read [the architecture](../../docs/ARCHITECTURE.md) for the connected flows and [the source reference](../../docs/reference/index.md) for module and function entry points. Current authority and owned file scope are rechecked at the mutation boundary. Provider authentication, funded admission and an outbound-effect grant remain separate contracts.

The first result selects an isolated owned state directory. Recipient service entry points and hidden credential input are documented in [setup](../../docs/SETUP.md).
